## Важный дисклеймер
Расписание — ориентировочное. Группа живёт в своём ритме, и ведущая адаптирует программу под состояние участниц. Не бывает двух одинаковых потоков.

## Типичный день (дни 2–4)

| Время | Активность |
|---|---|
| 07:30 | Подъём (мягкий, без будильника у соседок) |
| 08:00–08:45 | Утренняя практика: медитация или дыхательные упражнения |
| 09:00–09:45 | Завтрак |
| 10:00–12:30 | Основная сессия (арт-терапия или групповая работа) |
| 12:30–13:00 | Свободное время |
| 13:00–14:00 | Обед |
| 14:00–16:00 | Тихий час / свободное время / прогулка |
| 16:00–18:00 | Практика или прогулка с осознанным вниманием |
| 18:30–19:30 | Ужин |
| 20:00–21:30 | Вечерний круг / рефлексия / свободное общение |
| 22:00 | Тишина в пространстве (рекомендуется) |

## День приезда (День 1, 14 июня)

| Время | Активность |
|---|---|
| 12:00 | Сбор в аэропорту Минеральные Воды (выход А) |
| 12:00–14:00 | Трансфер на базу (~1,5–2 часа) |
| 14:00–16:00 | Заселение, знакомство с пространством |
| 17:00–18:30 | Вводная встреча группы, правила пространства |
| 19:00 | Первый совместный ужин |
| 20:00–21:30 | Вечерний круг знакомства |

## День отъезда (День 5, 18 июня)

| Время | Активность |
|---|---|
| 07:30 | Подъём |
| 08:00–08:45 | Финальная утренняя практика |
| 09:00–09:45 | Завтрак |
| 10:00–11:30 | Круг завершения и прощания |
| 11:30–12:00 | Сборы, сдача номеров |
| 12:00 | Выезд, обратный трансфер в аэропорт |

## Свободное время
Каждый день — **минимум 2 часа** личного времени:
- Прогулка в одиночестве
- Дневник и рефлексия
- Отдых и сон
- Неформальное общение с участницами
- Просто тишина

## Телефон и цифровой детокс
Рекомендуем убирать телефон на время практик и сессий. Для связи с семьёй лучше выделить конкретное время — например, после обеда (13:00–14:00).

## Часто задаваемые вопросы о режиме дня

**Когда завтрак на ретрите?**
Примерно в 09:00–09:45. Точное расписание объявляется на месте.

**Есть ли тихий час?**
Да. Каждый день с 14:00 до 16:00 — свободное время: тихий час, прогулка или отдых по желанию.

**Во сколько заканчивается вечерняя программа?**
Около 21:30. С 22:00 — тишина в пространстве (рекомендуется).

**Можно ли лечь спать раньше?**
Да. Вечерний круг — по желанию. Бережность к себе — главный принцип.
